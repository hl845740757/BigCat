# 项目说明

## Editor.Core

Editor.Core是开发工具的公共模块，工具模块基本都会依赖该模块。

Q：哪些代码放在这里？  
A：与具体业务无关的公共数据结构，包括：PB的内存表达，Excel的内存表达。

Q：哪些代码不能放这里？  
A：已具体业务相关的工具，比如：代码生成器。代码生成器通常与业务强相关，因此不适合放在公告包。

Q：为什么不Protobuf、Excel各一个程序集？  
A：那样可能造非常多的程序集，管理复杂度会急剧上升 -- 主要我们的Core包也不会有太多的代码。

## Protobuf文件规范

1. 字段、枚举和方法必须在单行内完成定义，不可以换行
2. Service、Message、Enum的结束符`}`需要换行
3. 文件名、顶层消息名、服务名不可重复 -- 方便定位
4. 仅支持单行注释`//`和行尾注释，不支持多行注释块`/** */`
5. 注释行与要注释的元素之间不可有空行，空行会中断注释累积。

注意：如果使用Protobuf定义BigCat项目约定的Rpc，更详细的规范见[proto文件规范](../../docs/Protobuf.md)
